# מתכנן שבוע — צבא, 75 Hard ושיעור קבלה

אבטיפוס Streamlit מקומי הממחיש את זרימת העבודה הבאה: הזנת שעות צבא שבועיות, בחירת זמן שיעור קבלה לכל יום, יצירת הצעת לו"ז שבועית, זיהוי התנגשויות והכנת הודעה להעתקה לעוזרת אישית.

## הפעלה

התקן את התלויות והפעל את האפליקציה מהתיקייה הזו:

```bash
sudo pip3 install -r requirements.txt
streamlit run app.py
```

האפליקציה תיפתח בדפדפן בכתובת שמודפסת במסוף, בדרך כלל `http://localhost:8501`.

## שימוש

תחילה בחר את יום ראשון של השבוע ואת הגדרות השינה והשיעור הקבועות. לאחר מכן הזן בטבלה את שעות הצבא, משך הנסיעה, בחירת שיעור הקבלה והערות לכל יום. אפשר גם להעלות קובץ CSV או Excel. לחץ על **"בנה לו״ז שבועי"**, בדוק התראות וחפיפות, ואז העתק את ההודעה המוכנה לעוזרת האישית.

## מבנה קובץ העלאה

האפליקציה מזהה כותרות נפוצות, כגון `יום`, `תחילת צבא`, `סיום צבא`, `נסיעות (דקות)`, `שיעור קבלה` ו־`הערה`. שעות יש להזין בפורמט `HH:MM`, למשל `08:00` ו־`12:00`.

| יום | תחילת צבא | סיום צבא | נסיעות (דקות) | שיעור קבלה | הערה |
|---|---|---|---:|---|---|
| ראשון 17/08 | 08:00 | 12:00 | 45 | 02:30 |  |
| שני 18/08 | 12:00 | 17:00 | 45 | ללא שיעור | יום עמוס |

## גבולות האבטיפוס

המנוע הוא מבוסס חוקים בלבד, ולכן הוא מציע תבניות התחלתיות ולא קובע שהלו"ז בר-ביצוע. יש לבדוק זמני נסיעה, זמינות חדר כושר, מחויבויות צבאיות ושינה לפני שליחה לעוזרת. האבטיפוס אינו שולח הודעות, אינו מתחבר ליומן, ואינו מעלה מידע לשירות חיצוני.

בגרסה הבאה מומלץ להוסיף קליטת תמונות OCR, שלושה מצבי יום (רגיל, צפוף והתאוששות), עריכה ידנית של אירועים וחיבור ליומן רק לאחר אישור מפורש של המשתמש.
